## أخطاء المرجع التي عولجت
- تعدد أرقام المصروفات: مصدر حساب واحد `computeReport` ولقطة إصدار محفوظة.
- ربح لا يطابق المعادلة: الإيراد − المصروفات، واختبار 19,903 − 12,432 = 7,471.
- إعادة بناء شهر سابق بلا فروقات: إصدارات وفروقات وبصمة مصادر.
- شهر مفقود: سلسلة أشهر تشمل الفراغ بعنوان «لا بيانات».
- خلط الإيراد بتكلفة الطبيب: جدول منفصل إيراد خدمات الطبيب مقابل أتعابه المستحقة.
- عام/أخرى ضخمة: منع الإصدار حتى إعادة التصنيف.
- خدمة بلا سعر معلن: إصدارات أسعار مؤرخة ورفض الصفر والتفاوض خارج القائمة.
- خصم غير موثق: سقف صلاحية وسبب وموافق وتاريخ.
- تعريفات متغيرة لمتوسط الفاتورة: تعريف واحد صافي الفواتير ÷ عددها.
- ديون متضاربة: دفتر ذمم ومقدمات وتخصيلات، والتحصيل القديم بلا تاريخ موسوم لا يختلق له شهر.
- حالة واجهة مطبوعة: منطقة الطباعة المالية لا تطبع الشريط الجانبي أو الدور الحالي.
- أقسام فارغة: «لا بيانات» صريحة بدلاً من النقاط الفارغة.
- مزج تاريخ الخدمة والدفع: شهر استحقاق وتاريخ دفع منفصلان.
- نسب لا تجمع ١٠٠٪: تقريب عشري مضبوط ليجمع 100 عند وجود إجمالي موجب.

## ما يلزم لقبول نهائي
1. إرفاق نسخة JSON الأصلية أو دفتر الزيارات/المصاريف وتقرير أكتوبر ٢٠٢٦ الأصلي.
2. إدخال سياسات الأطباء الحقيقية بالأرقام.
3. إعلان قائمة الأسعار وسعر الصرف وتكلفة استخدام المواد للشهر.
4. مراجعة بصرية لطباعة A4 على بيانات الإنتاج.
